How to read these numbers

Correct is the archived matches_answer_json result against the benchmark answer. Execution OK is the archived runner flag ok, not a correctness guarantee. A run can finish and still return the wrong answer. Individual tool errors can also be recovered before completion.

Call means use all 347 questions, including failures. Reasoning is the requested configuration, not proof of what a provider executed. Counts and archive checksums are validated during the site build; answers are not re-scored by this website.

Known gold-data caveat: two questions involving null birth-date ordering did not reproduce the stored gold answer during validation. Scores here remain unchanged. Gold validation · Benchmark protocol
